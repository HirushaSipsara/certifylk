# CertifyLK demo business and evidence-generation prompts

## Important use note

Everything in this guide is **fictional demo material** for CertifyLK testing,
presentations, and UI demonstrations. Do not submit these generated images or
documents to SLSI, CAA, a laboratory, a certification body, a buyer, or any
government authority. They are not proof of compliance, laboratory results, or
official records.

Use a consistent fictional business name in every generated item so the demo
looks coherent. For document evidence, generate the content below in a clean
one-page A4 layout and export it as a PDF. For photo evidence, generate a
realistic but clearly fictional documentary-style image; do not add official
logos, certificates, laboratory report branding, or signatures.
