# Chilli-paste sample

These JSON files document the deterministic demonstration inputs used by `POST /api/v1/assessments/sample`. The endpoint creates a fresh assessment and exercises the same profile, question planning, process extraction, evidence resolution, clarification, deterministic scoring, catalogue costing, and result persistence workflow as a manually completed assessment.

The sample intentionally contains both strengths and realistic preparation gaps. It is not a claim that the product or business is SLS certified.
